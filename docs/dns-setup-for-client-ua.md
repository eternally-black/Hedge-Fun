# Налаштування DNS для app.hedgeyour.fun — інструкція для власника домену

Потрібно додати **один DNS-запис**, щоб піддомен `app.hedgeyour.fun` вказував на наш сервер.
Основний сайт `hedgeyour.fun` це **НЕ зачіпає** — він і далі працюватиме як зараз.

## Що саме додати

Зайдіть у панель керування доменом `hedgeyour.fun` (там, де реєстрували домен —
GoDaddy / Namecheap / Cloudflare / тощо), знайдіть розділ **DNS** (або «DNS Records»,
«Керування зоною», «Zone Editor») і додайте новий запис:

| Поле | Значення |
|---|---|
| **Type (Тип)** | `A` |
| **Name / Host (Ім'я)** | `app` |
| **Value / Points to (Значення)** | `84.247.169.158` |
| **TTL** | `Automatic` або `3600` |
| **Proxy / Хмарка (якщо Cloudflare)** | **ВИМКНЕНО** (сіра хмарка, «DNS only») |

> Деякі панелі вимагають у полі «Name» писати повністю `app.hedgeyour.fun`, інші — лише `app`.
> Якщо є приклади існуючих записів — орієнтуйтесь на їхній формат.

## Важливо (Cloudflare)

Якщо домен на **Cloudflare** — біля запису буде помаранчева хмарка (проксі). Її треба
**вимкнути** (клікнути, щоб стала сірою — «DNS only»). Інакше наш HTTPS-сертифікат не
випуститься. Після запуску за бажанням можна буде ввімкнути назад, але спершу — вимкнено.

## Чого НЕ робити

- ❌ Не змінюйте і не видаляйте існуючий запис для `hedgeyour.fun` (кореня) — він тримає
  основний сайт (зараз вказує на `31.131.22.61`).
- ❌ Не міняйте NS-сервери / не переносьте домен.
- Додаєте **лише** новий запис для `app`.

## Після додавання

Зміни розходяться по інтернету від кількох хвилин до ~1 години (іноді довше).
Перевірити можна так: відкрити https://dnschecker.org , вставити `app.hedgeyour.fun`,
тип `A` — має показати `84.247.169.158`.

Як тільки запис з'явиться — напишіть нам, ми завершимо запуск (HTTPS підтягнеться
автоматично).
