================================================================================
  ЯК ЗАВЕСТИ X-ЗАСТОСУНОК І ДІСТАТИ OAuth-КЛЮЧІ ДЛЯ PRIVY
================================================================================

Статус: X-логін ЗАРАЗ ВИМКНЕНО в коді (loginMethods: ["email"]).
Ця інструкція — на потім, коли дійдуть руки увімкнути вхід через X (Twitter).


--------------------------------------------------------------------------------
  ЩО САМЕ ПОТРІБНО ДІСТАТИ
--------------------------------------------------------------------------------

Privy для логіну через X вимагає OAuth 2.0 креденшели:

  • Client ID
  • Client Secret

Не плутати зі старими API Key / API Secret для OAuth 1.0a —
Privy працює на OAuth 2.0.


--------------------------------------------------------------------------------
  КРОК 1. DEVELOPER-АКАУНТ НА X
--------------------------------------------------------------------------------

1. Зайди на developer.x.com під тим X-акаунтом, з якого керуватимеш
   застосунком.

2. Натисни Sign up / Developer Portal.
   Безкоштовного Free-тарифу достатньо для логіну (OAuth).
   Платні Basic/Pro потрібні лише для доступу до API-стрічок, НЕ для авторизації.

3. Заповни анкету use-case. Можна коротко:
   "User authentication / login for a web app via OAuth 2.0"


--------------------------------------------------------------------------------
  КРОК 2. СТВОРИТИ PROJECT + APP
--------------------------------------------------------------------------------

1. Developer Portal -> Projects & Apps -> Add Project
   (або Overview -> Create Project).

2. Дай назву проєкту (напр. "HedgeFun"), обери use-case.

3. Всередині проєкту створиться App — теж дай їй назву
   (напр. "HedgeFun Local" для дев-середовища).

   ПОРАДА: тримай ОКРЕМИЙ App під локалку і ОКРЕМИЙ під прод —
   у них різні Callback URL, і так не плутатимешся.


--------------------------------------------------------------------------------
  КРОК 3. УВІМКНУТИ USER AUTHENTICATION (OAuth 2.0)   [найважливіше]
--------------------------------------------------------------------------------

Без цього кроку НЕ зʼявляться Client ID / Client Secret.

1. У своєму App -> вкладка Settings -> блок "User authentication settings"
   -> Set up (або Edit).

2. App permissions: достатньо READ
   (треба лише прочитати профіль / username; запис не потрібен).

3. Type of App: обери "Web App, Automated App or Bot".
   Це confidential client — саме він видає Client Secret, потрібний Privy.
   (НЕ обирай Native / Public client — він НЕ дає Secret.)

4. App info — заповни URL-и:

   • Callback URI / Redirect URL:
     Вставляєш те, що дає PRIVY. У дашборді Privy на екрані налаштування
     Twitter/X показаний точний redirect URI — зазвичай це:

         https://auth.privy.io/api/v1/oauth/callback

     Скопіюй його ТОЧНО з дашборду Privy і встав сюди.
     (Колбек приймає Privy, а не твій localhost — тому localhost:3000
      тут НЕ потрібен.)

   • Website URL:
     Будь-який валідний. Для дева: http://localhost:3000
     Для прода: твій домен.

5. Збережи.


--------------------------------------------------------------------------------
  КРОК 4. СКОПІЮВАТИ CLIENT ID І CLIENT SECRET
--------------------------------------------------------------------------------

1. Після збереження User authentication відкриється екран із
   "OAuth 2.0 Client ID and Client Secret".

2. СКОПІЮЙ ОБИДВА ОДРАЗУ.
   Client Secret показується ЛИШЕ РАЗ. Якщо втратиш — регенеруй:
   Keys and tokens -> Regenerate.

3. Ці значення нікуди в код НЕ вставляються — вони йдуть ТІЛЬКИ в Privy.


--------------------------------------------------------------------------------
  КРОК 5. ВСТАВИТИ КЛЮЧІ В PRIVY
--------------------------------------------------------------------------------

1. dashboard.privy.io -> твій застосунок -> Login methods (Authentication)
   -> Twitter / X.

2. Встав Client ID і Client Secret з Кроку 4.

3. Звідти ж скопіюй Redirect URI, який показує Privy, і переконайся,
   що він ЗБІГАЄТЬСЯ з тим, що ти вписав у X (Крок 3.4).
   Мають бути ідентичні символ-у-символ.

4. Увімкни метод Twitter/X у Privy.


--------------------------------------------------------------------------------
  КРОК 6. ПОВЕРНУТИ X У КОД
--------------------------------------------------------------------------------

Файл: src/app/providers.tsx

   Було:  loginMethods: ["email"],
   Стане: loginMethods: ["email", "twitter"],

Скажи асистенту "вмикай X" — поверне рядок.


--------------------------------------------------------------------------------
  ЧАСТІ ГРАБЛІ
--------------------------------------------------------------------------------

  • redirect_uri mismatch
      -> Callback в X не збігається з тим, що в Privy.
         Лік: скопіювати redirect із Privy ДОСЛІВНО, без зайвого "/" в кінці.

  • Немає Client Secret
      -> Обрано не той тип App (Native / Public client).
         Треба Web App / Confidential client.

  • Загубив Secret
      -> Keys and tokens -> Regenerate, і онови значення в Privy.

  • Free vs платний
      -> Для логіну вистачає Free. Платні тарифи для логіну НЕ потрібні.
